## 这是什么

一个 Manifest V3 的 Chrome 扩展，做三件事：

1. **自动回复**：在 BOSS 直聘聊天页按规则自动回复指定会话
2. **模板管理**：预设回复话术，按场景选用
3. **LLM 生成**：可接国内大模型生成更自然的回复

## 功能

- 按会话列表批量处理
- 回复模板与变量替换
- 可接入 Kimi / DeepSeek 等模型生成回复
- 本地存储配置，不上传服务器

## 安装

1. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本仓库目录
4. 打开 BOSS 直聘网页，点扩展图标开始配置

## 配置

首次使用需要在扩展弹窗里填写：

- 回复模板
- 如果你想用 LLM 生成，填模型 API 地址与密钥（**只存在本地浏览器存储里**）

## 目录

```
├── manifest.json     扩展清单（Manifest V3）
├── background.js     后台服务
├── content.js        页面注入脚本
├── popup.html/js     配置界面
└── icons/
```
